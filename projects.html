Nexus Semantic Delta Patching Engine

Why I built it: I got sick of turning on my Xbox One S to play a game, only to be hit with a mandatory 40GB update for a minor patch or seasonal tweak. It takes up local storage, wastes internet bandwidth, and stops you from actually playing.

How it works: Most game engines overwrite giant files when making small updates. Nexus breaks data down into a structure-aware key-value tree. Instead of re-downloading the entire asset bundle, it surgically calculates the exact JSON keys that changed and patches only those key-value pairs locally.

Key Results
Reduced local patch payloads from gigabytes down to kilobytes without corrupting file line offsets.

BrickOwl Relational Inventory Scraper

Why I built it: As an avid LEGO collector managing sets and custom builds, tracking down individual part IDs across thousands of categories manually was painfully slow. Third-party sites didn't offer a clean way to pull relational data for personal inventory tracking.

How it works: I designed an ethical web scraper that respects server bandwidth limits using rate-limiting algorithms. It extracts complex element catalogs from BrickOwl and structures them into a clean relational graph model (Set -> Part -> Color -> Element ID), making custom collection analysis easy.

Key Features
Exponential backoff pacing, clean node-edge data mapping, and zero server strain.
