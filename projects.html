Nexus Semantic Delta Patching Engine

The Origin Story: I got tired of waiting on my Xbox One S for mandatory 40GB game updates just to play a quick match. Monolithic game updates waste storage, consume massive bandwidth, and block gameplay.

How it Works: Nexus parses JSON key-value data structures to isolate exact edits locally. Instead of overwriting whole asset archives, it generates a surgical delta patch that applies changes right on the local drive.

Key Result
Reduced patch sizes from tens of gigabytes down to lightweight kilobytes without file corruption.

BrickOwl LEGO Relational Inventory Scraper

The Origin Story: As a lifelong LEGO enthusiast managing complex sets and custom builds, tracking down individual part numbers, color variants, and element IDs across giant catalog databases manually was a huge bottleneck.

How it Works: I built an automated web scraper bot and data extraction agent designed specifically for LEGO cataloging on BrickOwl. It parses complex multi-part listings, respects site bandwidth with intelligent rate-limiting algorithms, and outputs clean relational graph models (Set -> Part -> Color -> Element ID).

Key Features
Ethical request pacing with exponential backoff, complete LEGO part mapping, and graph-ready inventory files.
